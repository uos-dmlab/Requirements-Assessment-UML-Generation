# ChatGPT Mermaid — Use Case Diagram Results

## Status: Not Supported

Mermaid's diagram renderer does not support use case diagram syntax. When prompted to generate use case diagrams using Mermaid, ChatGPT produced code that displayed "Diagram is not supported."

This is reported as "N/S" (Not Supported) in Table I of the paper.

### Evidence

ChatGPT generated Mermaid code but its renderer showed "Diagram is not supported" for all 5 use case test cases. No valid diagrams were produced.
